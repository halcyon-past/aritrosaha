## 🚀 Featured Software & Open Source

### 1. [Byakugan Scan](https://github.com/halcyon-past/byakugan-scan)
*Instant, in-memory screen OCR, QR code, and barcode scanner for macOS (Swift 6.0, AppKit, Apple Vision).*
- **Zero Disk Writes**: Captures screen regions straight into `NSPasteboard` as in-memory `CGImage` buffers, eliminating `mdwrite` and `MADService` disk stalls.
- **Apple Neural Engine**: Sub-50ms OCR processing across 13+ languages.
- **AlternativeTo**: [Byakugan Scan on AlternativeTo](https://alternativeto.net/software/byakugan-scan/about/)
- **Product Hunt**: [Byakugan Scan on Product Hunt](https://www.producthunt.com/products/byakugan-scan)
```bash
brew install --cask halcyon-past/tap/byakugan-scan
```

### 2. [SutraKey](https://github.com/halcyon-past/SutraKey)
*Shift + Select liquid radial menu for instant media & clean document actions on macOS.*
- **Zero Idle CPU**: Pure Swift 6 + AppKit `CGEventTap` with zero background telemetry or Electron bloat.
- **Instant Actions**: 4K Video (yt-dlp), 320kbps MP3 Audio, Subtitles, and Ad-free Clean PDFs straight to `~/Downloads`.
- **AlternativeTo**: [SutraKey on AlternativeTo](https://alternativeto.net/software/sutrakey/about/)
- **Product Hunt**: [SutraKey on Product Hunt](https://www.producthunt.com/products/sutrakey)
```bash
brew install --cask halcyon-past/tap/sutrakey
```

### 3. [Quarantine (`quarantine-py`)](https://github.com/halcyon-past/quarantine)
*Zero-dependency fault-tolerance decorator and atomic dead-letter queue for Python batch loops.*
- Published on [PyPI](https://pypi.org/project/quarantine-py/).
```bash
pip install quarantine-py
```

### 4. [OpenWorld Portfolio](https://github.com/halcyon-past/openworld-portfolio)
*Interactive 2.5D retro Pokémon RPG-themed developer world in Pallet Cloud.*
- Built completely from scratch with Next.js 16, React 19, and native HTML5 Canvas 2D without third-party game engines.
- Live: [openworld.aritro.cloud](https://openworld.aritro.cloud)
